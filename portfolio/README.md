# Как добавлять видео на сайт

Положите видео в нужную папку. Каждый файл станет отдельной VHS-кассетой в видеотеке. Код и списки работ редактировать не нужно.

| Папка | Раздел на сайте |
| --- | --- |
| `AI/avatars` | AI → Аватары |
| `AI/campaigns` | AI → Рекламные проекты |
| `AI/experiments` | AI → Эксперименты |
| `Motion/commercials` | Motion → Реклама |
| `Motion/product-3d` | Motion → Продукт и 3D |
| `Motion/gambling` | Motion → Гемблинг |
| `Motion/crypto` | Motion → Крипта |
| `Motion/other` | Motion → Другие работы |

## Самый простой способ

1. Откройте локальную папку репозитория `vibepotfolio/portfolio` и выберите категорию.
2. Скопируйте туда видео, например `AI/avatars/Виртуальный ведущий.mp4`.
3. В GitHub Desktop выберите репозиторий `vibepotfolio`. Проверьте список изменений, напишите короткое описание и нажмите **Commit to main**, затем **Push origin**. Если Desktop предлагает **Fetch origin**, сначала нажмите его; при необходимости выполните **Pull origin**, затем отправьте свои изменения.
4. Дождитесь успешного развёртывания Vercel и обновите сайт. Кассета появится автоматически. Перемещение файла в другую категорию или удаление файла обновит каталог при следующей публикации.

Копирование файла только на компьютер не меняет опубликованный сайт. На сайте нет общедоступной формы загрузки: публикация выполняется через ваш доступ к GitHub.

Можно также открыть нужную папку в [GitHub](https://github.com/nikitakasp-ship-it/vibepotfolio/tree/main/portfolio), выбрать **Add file → Upload files** и сохранить изменения в `main`. Через браузер GitHub принимает файлы до 25 MiB; GitHub Desktop позволяет отправлять файлы менее 100 MiB. Более крупное видео нужно сжать или разделить. Если библиотека станет большой, её лучше перенести в отдельное видеохранилище.

## Формат и название

- Предпочтительно **MP4, видео H.264, звук AAC**, с опцией экспорта «Web optimized» / «Fast start». Также поддерживается WebM; совместимость зависит от кодеков и браузера.
- Для портфолио обычно достаточно 1080p. Размер каждого файла должен быть менее 100 MiB.
- Имя файла становится названием работы; `_` и `-` заменяются пробелами. Кириллица, пробелы и вложенные папки проектов поддерживаются.
- Для своей обложки добавьте рядом картинку с тем же именем: `Виртуальный ведущий.jpg` (также `.jpeg`, `.png`, `.webp`). Без картинки сайт создаст стандартную VHS-обложку.
- Новая подпапка прямо внутри AI или Motion станет новой категорией. Её название будет показано как есть. Вложенные папки внутри существующей категории остаются частью этой категории.
- Видео появятся в «Все работы». Демонстрационные кассеты останутся в разделе «Демо»; пока своих видео нет, они также показаны в общем списке.

## Необязательно: названия и описания на двух языках

Рядом с `Виртуальный ведущий.mp4` можно сохранить `Виртуальный ведущий.json`:

```json
{
  "title": {"ru": "Виртуальный ведущий", "en": "Virtual presenter"},
  "description": {
    "ru": "AI-аватар для презентации продукта. Концепция, генерация и монтаж.",
    "en": "An AI avatar for a product presentation. Concept, generation and editing."
  }
}
```

Без этого файла достаточно самого видео. Название будет одинаковым для обеих языковых версий.

## Локальный просмотр до публикации

После добавления или удаления видео дважды нажмите **Обновить каталог.cmd** в корне сайта (нужен установленный Node.js). Затем обновите локальный сайт. Открывайте сайт через локальный HTTP-сервер, не двойным щелчком по `index.html`. Для опубликованного сайта этот шаг не нужен: Vercel запускает сборку автоматически.

Техническая проверка: `node --test scripts/catalog.test.mjs`. Полная сборка: `node scripts/build-site.mjs` (результат в `dist`).
