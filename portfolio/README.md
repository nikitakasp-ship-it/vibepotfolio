# Как добавлять видео на сайт

Положите MP4 или WebM размером меньше 100 МБ в папку категории. Сайт сам добавит работу в библиотеку, а кадр из видео станет обложкой кассеты.

Сейчас есть категории `AI/avatars`, `AI/experiments`, `Motion/commercials`, `Motion/gambling`, `Motion/JDM` и `Motion/PSY`. Пустые категории не показываются. Можно создать собственную подпапку внутри AI или Motion — она появится в библиотеке вместе с первой работой.

1. Скопируйте видео в подходящую папку, например `AI/avatars/Виртуальный ведущий.mp4`.
2. Установите Node.js и FFmpeg, затем дважды нажмите **Обновить каталог.cmd**. Команда создаст рядом с видео обложку JPG из кадра ролика и обновит каталог. Для роликов, у которых уже есть обложки, ничего повторно генерировать не нужно.
3. Добавьте видео и созданные JPG-файлы в GitHub Desktop, нажмите **Commit to main** и **Push origin**. Видео должны быть меньше 100 МБ, иначе GitHub отклонит push.
4. Перезагрузите локальный сайт через HTTP-сервер, чтобы проверить работу и кадры.

Для сайта лучше подходят MP4 H.264 с AAC, разрешение до 1080p. Каждая обложка имеет то же имя, что и видео, но расширение `.jpg`; кадры сохраняются шириной до 640 пикселей.

Чтобы добавить перевод названия или описания, сохраните рядом с видео JSON-файл с тем же именем:

```json
{"title":{"ru":"Виртуальный ведущий","en":"Virtual presenter"},"description":{"ru":"AI-аватар для презентации продукта.","en":"An AI avatar for a product presentation."}}
```

Проверки каталога: `node --test scripts/catalog.test.mjs`. Локальная production-сборка: `node scripts/build-site.mjs` (результат в `dist`).
