# Как добавлять видео на сайт

Положите MP4 или WebM в папку категории. Название файла появится на VHS кассете автоматически.

Папки: `AI/avatars` (Аватары), `AI/campaigns` (Рекламные проекты), `AI/experiments` (Эксперименты), `Motion/commercials` (Реклама), `Motion/product-3d` (Продукт и 3D), `Motion/gambling` (Гемблинг), `Motion/crypto` (Крипта), `Motion/other` (Другие работы). Папки категорий созданы пустыми. Можно добавлять свои подпапки внутри AI/Motion — сайт покажет их как новые категории.

1. Положите видео в нужную папку, например `AI/avatars/Виртуальный ведущий.mp4`. При желании добавьте рядом постер с тем же именем (`.jpg`, `.jpeg`, `.png`, `.webp`).
2. В GitHub Desktop выберите репозиторий `vibepotfolio`, проверьте изменения и нажмите **Commit to main**, затем **Push origin**. Vercel соберёт видеотеку и обновит опубликованный сайт автоматически. Простое копирование видео на компьютер сайт онлайн не обновляет.
3. Для локального просмотра дважды нажмите **Обновить каталог.cmd**, затем перезагрузите открытый локальный сайт через HTTP-сервер. Node.js должен быть установлен.

Видеотека сразу показывает два раздела: AI и Motion. Выберите один из них, затем категорию и свою видеокассету. На физической полке эти разделы и категории представлены тематическими кассетами.

Используйте MP4 H.264 с AAC, лучше 1080p и меньше 100 MiB на файл. Более крупные файлы сожмите или разделите. Через браузер GitHub можно загрузить до 25 MiB; GitHub Desktop принимает файлы менее 100 MiB. При большом портфолио лучше перенести видео в отдельное видеохранилище.

Чтобы добавить перевод названия/описания, сохраните рядом `Виртуальный ведущий.json` с таким содержимым:

```json
{"title":{"ru":"Виртуальный ведущий","en":"Virtual presenter"},"description":{"ru":"AI-аватар для презентации продукта.","en":"An AI avatar for a product presentation."}}
```

Проверки каталога: `node --test scripts/catalog.test.mjs`. Локальная production-сборка: `node scripts/build-site.mjs` (результат в `dist`).
